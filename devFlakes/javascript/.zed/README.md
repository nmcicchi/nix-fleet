# Project Zed Setup

## Recommended Extensions
- `live-server` — Used for launching a local dev server directly within Zed.

## Installation
Run the following in Zed:
1. Open Command Palette (`Ctrl+Shift+P`) -> `zed: extensions`.
2. Search and install `live-server`.

Alternatively, ensure `"live-server"` is listed in your `zed.nix` Home Manager extensions array.
